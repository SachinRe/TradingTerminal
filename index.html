Import Charles Schwab History CSV export · safe to run daily, even multiple times a day
Export trade history from Schwab as Transactions (CSV) — the file with Date, Action, Symbol, Quantity, Price, Fees & Comm, Amount columns. Buy/Sell rows are matched FIFO per ticker into real round-trip trades (correct realized P&L), remaining unmatched shares become Open Positions. Automatically de-duplicated — Schwab exports your full history every time, so re-importing the same file, or a file that overlaps with a previous import, will not double-count anything. Only genuinely new transactions get processed. Options rows (spaces in the symbol) are currently skipped — dividends/interest rows are skipped too.
