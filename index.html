Market Advance/Decline · Via Your Google Sheet Zero FMP budget used
One-time setup required. GOOGLEFINANCE only works inside actual spreadsheet cells — Apps Script can't call it directly — so the design is: a Sheet with a GOOGLEFINANCE formula per ticker, an Apps Script doGet() that reads those calculated values, deployed as a public URL your browser fetches directly. Nothing here touches your FMP quota. Honest caveat: Google's terms describe GOOGLEFINANCE as personal/non-commercial use, "as-is," not guaranteed for accuracy or timeliness — treat this as a delayed, best-effort count, not a certified real-time feed.
Setup instructions + script to paste
1. Create a new Google Sheet. Rename the first tab to exactly Breadth.
2. In column A, paste your ticker list starting at A2 (A1 = header). Column B, row 2, enter: =GOOGLEFINANCE(A2,"changepct") — then drag that formula down for every ticker row.
3. Extensions → Apps Script. Delete the default code and paste this: 
function doGet(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName("Breadth");
  var lastRow = sheet.getLastRow();
  var data = sheet.getRange("B2:B" + lastRow).getValues();
  var up = 0, down = 0, unchanged = 0;
  data.forEach(function(row) {
    var val = row[0];
    if (typeof val === "number") {
      if (val > 0) up++;
      else if (val < 0) down++;
      else unchanged++;
    }
  });
  var result = {
    up: up, down: down, unchanged: unchanged,
    total: up + down + unchanged,
    generatedAt: new Date().toISOString()
  };
  return ContentService.createTextOutput(JSON.stringify(result))
    .setMimeType(ContentService.MimeType.JSON);
}
4. Deploy → New deployment → Type: Web app. "Execute as": Me. "Who has access": Anyone. Click Deploy, authorize it, then copy the Web App URL it gives you.
5. Paste that URL below and save.

Checklist From your McClellan notes + an independent backtest study
QQQ EMAs
The switch — check this first
10dma above 20dma → Participate
10dma below 20dma → No new risk
Why
The only rule that held up on genuinely out-of-sample data across 1,000s of real breakout trades (+2.35R, range +0.62 to +4.14 — the only result in the whole study excluding zero on fresh data). Beat every breadth indicator tested, McClellan included. Check manually — not automated in this app.
MCO
MCO is timing
< −1σ → watch for a bounce
< −2σ → watch for a major reversal
Why
Short-term breadth momentum: NDX daily advancers − decliners, smoothed as 19-day EMA minus 39-day EMA. Deeply negative = washed out, elevated fear, "selling climax" shifting toward "snapback potential" — like a rubber band stretched too far. Caution: an independent backtest found McClellan-style measures were "the weak and inverted ones," and several experienced traders dropped NAMO/NASI/T2108/put-call ratio after false signals in sustained trends. Use as a read, not an on/off switch.
MCSI
MCSI is confirmation
Curl-up → pilot size
Reclaims 10dma → press with conviction
Curl-down → halt new risk
Why
Long-term breadth trend: the running cumulative total of MCO, compared to its own 10-day moving average. Reclaiming the 10dma is the moment breadth actually turns structurally, not just a bounce. Same caution as MCO applies.

THE HOLY GRAIL OF TRADING
There isn't a secret setup. There's this, done consistently:
MARRY A SETUP
Stop rotating between five methods. Pick one structure. Give it months, not a weekend, before you judge it.
+
🔁
BUILD PROCEDURAL MEMORY
Run the same six-step loop, every single day, until it fires without you thinking — not once a week when a setup happens to appear.
Neither one works alone. A setup with no daily repetition never becomes a skill. Daily repetition on a setup you keep switching never compounds.
STOP FLIRTING WITH ONE SETUP AND ANOTHER
A setup is only an idea until you turn it into a process you can run in your sleep.
01 Do not mix setups from two different sources.
02 Do not pile indicators onto a clean structure.
03 A good setup is structural — price and context first.
It takes months to get good at one setup. If you will not put that work into one structure, you will go nowhere.
The Temptation Is the Product

In a day you can see twenty new setups — YouTube, X, Discord, Substack, a new book, a highlighted trade everyone suddenly wants. The chart looks different. The indicators look smarter. So you try it.

That is how most traders spend years: sampling. They never stay with one structure long enough to get good. Months of work get replaced by a weekend of novelty. Nothing compounds.

Traders who last ten years or more trade the same setup over and over. The market changes. The names change. The setup does not.
Your Job Is to Develop Procedural Memory, Not Find More Ideas

An idea does not trade. A process trades. Until you convert the setup into a repeatable loop, it is not yours — it is a screenshot you borrowed.

Procedural memory is the memory of how to do a thing — riding a bike, scanning, picking, sizing, stopping, and exiting a breakout. The brain stores the whole sequence as one unit. When the setup appears, the sequence fires. You do not negotiate with yourself about step four.

That memory only forms after you do the same steps, in the same order, many times. Flirting resets the clock — you stay a beginner at five methods instead of becoming dangerous at one.

One Loop, Run Daily Scan → Identify → Size → Stop → Target → Exit
Individual trades do not matter. Process flow does. If you can run the flow, you can find the next trade. If you only collect examples, you will wait for someone else to highlight one.

↓

A breakout is not "buy strength." It is that entire chain — and the chain is the skill, not any single trade inside it.

Follow people only when they can show the loop — step one, step two, step three, and why those steps exist. If they cannot, you are watching a highlight reel.
This loop maps directly onto this terminal's own flow: Discover & Qualify (Scan/Identify) → Watchlist & Plans (Size/Stop/Target) → Positions (Exit). The tools already exist — the discipline is running the same six steps every single day, on one setup, until it's automatic. That's not a metaphor here: your own Process Flow → Daily tab is that literal closed loop, running Pre-Market → During Market Hours → Near Close → Post Market → back to Pre-Market tomorrow. Procedural memory isn't built by reading this page once — it's built by running that page's cycle, daily, on the one setup you married.
Practice the Right Process, or You Will Have to Unlearn It

Procedural memory is durable. That is the gift and the trap. Learn the wrong sequence and it sticks. Get the process right first — then repeat it until you can run it half-asleep.

Six months of one setup will do more than six years of rotating through other people's charts. If you wake up in the middle of the night, you should still be able to run the process without thinking.
There Are Not a Hundred Setups
Almost everything you will see this year is a rehash of a few old families. Pick one. Write the process. Trade only that for six months.

If you want to make money trading, stop chasing setup ideas.

Afternoon · 2:00pm – 3:50pm
Anticipation scans (3 variants)
Buys BEFORE the breakout — a stock "coiled" through tight, narrow-range days. Building tomorrow's watchlist, not today's trade.
The 3 variants
ANTS 15: first leg ≥15% gain in last 10 days · tight day ±0.4% · Price >$3 · Volume >900K (3-day)
Momentum ANTS: up 20%+ from low OR avg close(7)/avg close(65) ≥1.05 · tight day ±0.4% · |Δ$| <0.40
High-Price ANTS (FHP): Price >$60 · tight day ±0.25% · net change <$0.50
Sort by Net Change ascending — tightest, most "compressed" stocks surface first.
Reversal / Exhaustion scan
Supporting, not leading — selling exhausted, last seller sold, buyers step back in. Ask "who buys this tomorrow?"
Conditions & sort
Today = lowest close of last 3 trading days, BUT closes in top 60% of intraday range (strong recovery off the low)
Volume >900K · Price >$5
Sort by Volume, then qualitative overlay — "fund quality" and genuinely popular.
